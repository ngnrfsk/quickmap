# Task 1E.1: Fix Legend Text and Marker Scaling Issues

## Overview
Correct scaling problems identified in Task 1E testing where legend text and marker sizes don't scale appropriately across different image dimensions. The STANDARD map (1200x1200) should serve as the baseline for optimal sizing.

## Current Problems Identified

### Legend Text Scaling Issues
- **SMALL maps (800x600)**: Legend text too small, difficult to read
- **LARGE maps (1920x1080)**: Legend text too large, wastes space
- **POSTER maps (2400x1800)**: Legend text excessively large, poor proportions
- **STANDARD maps (1200x1200)**: Correct sizing (baseline reference)

### Marker Size Problems
- **All image sizes**: Markers remain the same absolute size regardless of image dimensions
- **SMALL maps**: Markers appear relatively large compared to map area
- **LARGE/POSTER maps**: Markers appear too small, hard to see in high-resolution exports

### Legend Layout Issues
- **Legend height**: Fixed height doesn't scale with image size
- **Gaps and padding**: Static values don't adjust proportionally
- **Overall legend size**: Should be smaller on standard maps, larger on big maps

## Root Cause Analysis

### Current Scaling Implementation
```r
# Current scaling logic (lines 1093-1107 in quickmap_0_8_7.R)
scale_factor <- min(width / 1200, height / 1200)
banner_font_size <- 1.8 * scale_factor
symbol_size <- 2 * scale_factor
header_font_size <- 1.2 * scale_factor
legend_font_size <- 1.0 * scale_factor
```

**Problems:**
1. **Using minimum dimension**: `min(width/1200, height/1200)` causes under-scaling for non-square images
2. **Legend text scaling**: Only CSS text sizes scale, not legend data text
3. **Marker scaling**: Map markers don't scale with image dimensions at all
4. **Layout scaling**: Padding, gaps, and legend height remain fixed

## Proposed Solutions

### 1. Improve Scale Factor Calculation
Replace minimum-based scaling with dimension-aware scaling:

```r
# Current problematic calculation
scale_factor <- min(width / 1200, height / 1200)

# Proposed improvement - use geometric mean for balanced scaling
scale_factor <- sqrt((width * height) / (1200 * 1200))

# Alternative: Use average dimension for more predictable scaling
# scale_factor <- ((width / 1200) + (height / 1200)) / 2
```

**Benefits:**
- Better scaling for non-square images
- More proportional sizing across different aspect ratios
- Prevents extreme under-scaling on widescreen formats

### 3. Scale Legend Layout Dimensions
Extend CSS scaling to include layout properties:

```r
  custom_css <- gsub("2rem", paste0(symbol_size, "rem"), custom_css)

```
