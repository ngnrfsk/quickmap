# QuickMap v0.9.0 Parameter Changes

**Date:** 2025-10-28
**Version:** 0.8.11 → 0.9.0
**Reduction:** 21 → 14 parameters (33% reduction)
**Code Reduction:** 2485 → 2427 lines (58 lines, 2.3%)

---

## Summary

Following OpenAir R package design patterns, parameters now describe WHAT user wants (not HOW it's implemented), with sensible defaults and clear naming.

## Changes by Type

### Renamed (6)
| Old Name | New Name | Reason |
|----------|----------|--------|
| `years_to_plot` | `years` | Shorter, context clear |
| `vignette_overlay_on` | `vignette` | Remove redundant "_on" |
| `csv_data_file` | `diffusion_tube_file` | Self-documenting |
| `oa_data_file` | `sensor_file` | Self-documenting |
| `show_marker_labels` | `marker_labels` | Remove "show_" prefix |
| `show_boundary_labels` | `boundary_labels` | Remove "show_" prefix |

### Merged (7 → 3)

**Image Export (3 → 1):**
- `image_export` + `map_width_px` + `map_height_px` → `export_image`
- Usage: `export_image = NULL` or `export_image = c(1920, 1080)`

**Title (2 → 1):**
- `html_page_title` + `banner_text` → `title`
- Single text for both browser tab and banner

**Styling (4 → 1):**
- `show_banner` + `show_title` + `show_legend` + `title_prefix` → `styling_type`
- Values: `"none"` or `"html"`

### Removed
- Leaflet legend controls (28 lines)
- Leaflet title controls (6 lines)
- Complex parameter unpacking (15 lines)
- Unused code paths (9 lines)

## Migration Examples

### Before (v0.8.11)
```r
create_pollution_map(
  csv_data_file = "~/data/tubes.csv",
  oa_data_file = "~/data/sensors.Rdata",
  boroughs = "Wandsworth",
  years_to_plot = c(2022, 2023, 2024),
  vignette_overlay_on = TRUE,
  show_marker_labels = "values_on",
  show_boundary_labels = FALSE,
  image_export = TRUE,
  map_width_px = 1920,
  map_height_px = 1080,
  html_page_title = "Air Quality",
  banner_text = "Wandsworth Air Quality Dashboard",
  show_banner = TRUE,
  show_legend = FALSE,
  show_title = FALSE,
  output_file = "wandsworth_map.html"
)
```

### After (v0.9.0)
```r
create_pollution_map(
  diffusion_tube_file = "~/data/tubes.csv",
  sensor_file = "~/data/sensors.Rdata",
  boroughs = "Wandsworth",
  years = c(2022, 2023, 2024),
  vignette = TRUE,
  marker_labels = "values_on",
  boundary_labels = FALSE,
  export_image = c(1920, 1080),
  title = "Wandsworth Air Quality Dashboard",
  styling_type = "html",
  output_file = "wandsworth_map.html"
)
```

## Benefits

### Clearer Intent
- Parameters describe WHAT not HOW
- `styling_type = "html"` clearer than 4 separate show_* flags
- `export_image = c(1920, 1080)` clearer than 3 separate parameters

### Simpler API
- 33% fewer parameters overall
- Consistent naming (no "show_" prefixes)
- Self-documenting names (diffusion_tube_file vs csv_data_file)

### Less Code
- 58 lines removed (2.3%)
- Simpler parameter handling
- No leaflet control complexity

### Better Defaults
- `styling_type = "none"` (clean maps by default)
- `export_image = NULL` (HTML-only by default)
- Fewer decisions for basic use cases
