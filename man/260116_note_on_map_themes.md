# Map themes

**Map themes** can be set via the map:base_time parameter in the themes YAML files, for example

``` r
map: base_tiles: "CartoDB.Positron"
```

## Light themes

-   "CartoDB.Positron" \# Clean light (matches airstat)

-   "CartoDB.PositronNoLabels" \# Same but no labels

-   "CartoDB.Voyager" \# Light with more detail

## Dark themes

-   "CartoDB.DarkMatter" \# Clean dark theme

-   "CartoDB.DarkMatterNoLabels" \# Dark without labels

## Alternatives

-   "Esri.WorldGrayCanvas" \# Muted gray

-   "Stadia.AlidadeSmooth" \# Clean modern (requires API key)
