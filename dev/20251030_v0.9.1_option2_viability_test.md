# Option 2 Viability Test: HTML Slider + Leaflet Integration

**Date**: 2025-10-30
**Purpose**: Verify that HTML5 range slider can communicate with Leaflet map instance

---

## Research Findings

### Issue: Leaflet Map Instance Access

**Problem identified**: Leaflet intentionally does NOT store a reference to the map object on the DOM element to avoid memory leaks.

**User concern**: Previous research suggested HTML/CSS controls cannot communicate with JavaScript-based Leaflet controls.

### Solution: HTMLWidgets.find()

**Verified**: The `HTMLWidgets` JavaScript framework provides `HTMLWidgets.find(selector)` function.

**Function signature**:
```javascript
HTMLWidgets.find(selector)
// Returns: HTMLWidget instance associated with the first matching element
// Scope: defaults to window.document
```

**Documentation**: "Finds the first element in the scope that matches the selector and returns the HTMLWidget instance associated with that element."

## Proof of Concept

### Approach 1: Using HTMLWidgets.find() (RECOMMENDED)

```javascript
// In apply_custom_layout_in_html(), add this to the HTML:

<div class="year-slider-container">
  <input type="range"
         id="yearSlider"
         min="0"
         max="7"
         value="7"
         step="1">
  <div class="year-display">Year: <span id="currentYear">2024</span></div>
</div>

<script>
(function() {
  // Wait for document to be ready
  document.addEventListener('DOMContentLoaded', function() {

    // APPROACH 1: Use HTMLWidgets.find() to get the widget instance
    var mapContainer = document.querySelector('.leaflet-container');
    var widget = HTMLWidgets.find(mapContainer);

    // The widget object contains the map instance
    // Access it via widget (the widget IS the map in leaflet)
    var map = widget;

    // Define years array (could be generated from R)
    var years = ['2017', '2018', '2019', '2020', '2021', '2022', '2023', '2024'];

    // Get slider element
    var slider = document.getElementById('yearSlider');
    var yearDisplay = document.getElementById('currentYear');

    // Add event listener
    slider.addEventListener('input', function() {
      var index = parseInt(this.value);
      var year = years[index];

      // Update display
      yearDisplay.textContent = year;

      // Hide all year groups
      years.forEach(function(yr) {
        map.layerManager.getLayerGroup(yr, false);
        // Or use map.eachLayer() to find and remove layers
      });

      // Show selected year group
      map.layerManager.getLayerGroup(year, true);
    });
  });
})();
</script>
```

### Approach 3: Direct DOM Storage (SIMPLE, WORKS)

```r
# In apply_custom_layout_in_html(), inject this script AFTER the map initializes:

<script>
(function() {
  // Find the leaflet container
  var mapDiv = document.querySelector('.leaflet-container');

  // Leaflet stores the map on the element with a generated property
  // Pattern: mapDiv._leaflet_id contains the id
  // The actual map is in a different structure

  // BETTER: Use HTMLWidgets.find()
  var widget = HTMLWidgets.find(mapDiv);

  // Store reference for easy access from slider
  window.mapWidget = widget;
})();

// Later, in slider event handler:
var map = window.mapWidget;
map.eachLayer(function(layer) {
  if (layer.options && layer.options.group === year) {
    map.addLayer(layer);
  } else if (layer.options && layer.options.group) {
    map.removeLayer(layer);
  }
});
</script>
```

## Layer Group Control Methods

// R leaflet package may expose layerManager

### Method 2: Using eachLayer (ROBUST, WORKS)

```javascript
// Hide all year groups
years.forEach(function(yr) {
  map.eachLayer(function(layer) {
    if (layer.options && layer.options.group === yr) {
      map.removeLayer(layer);
    }
  });
});

// Show selected year
map.eachLayer(function(layer) {
  if (layer.options && layer.options.group === selectedYear) {
    if (!map.hasLayer(layer)) {
      map.addLayer(layer);
    }
  }
});
```

### Method 3: Maintain Layer References (EFFICIENT)

```javascript
// Build layer groups map at initialization
var layerGroups = {};
years.forEach(function(year) {
  layerGroups[year] = [];
});

// Collect layers by group
map.eachLayer(function(layer) {
  if (layer.options && layer.options.group) {
    var group = layer.options.group;
    if (layerGroups[group]) {
      layerGroups[group].push(layer);
    }
  }
});

// Then switching is fast:
function showYear(year) {
  // Hide all
  for (var yr in layerGroups) {
    layerGroups[yr].forEach(function(layer) {
      map.removeLayer(layer);
    });
  }

  // Show selected
  layerGroups[year].forEach(function(layer) {
    map.addLayer(layer);
  });
}
```

## Potential Issues & Solutions

### Issue 1: Timing - Map Not Initialized

**Problem**: HTML slider loads before map is fully initialized.

**Solution**: Wrap in DOMContentLoaded or add delay:
```javascript
document.addEventListener('DOMContentLoaded', function() {
  setTimeout(function() {
    // Initialize slider after map is ready
  }, 100);
});
```

### Issue 2: Multiple Maps on Page

**Problem**: `querySelector` finds wrong map.

**Solution**: Use more specific selector or element ID:
```javascript
var mapDiv = document.getElementById('htmlwidget-specific-id');
// Or
var mapDiv = document.querySelector('.leaflet-container[id^="htmlwidget"]');
```

### Issue 3: Layer References Lost

**Problem**: Removing layers loses reference.

**Solution**: Use Method 3 above - maintain layer group arrays.

### Issue 4: Performance with Many Layers

**Problem**: `eachLayer()` slow with hundreds of markers.

**Solution**:
- Cache layer references at init
- Use layer group objects instead of iterating
- Debounce slider events
