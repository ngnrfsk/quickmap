## Implementation Steps

### Step 1: Add Helper Function to quickmap.R

Add this function somewhere before `create_pollution_map()` (~line 800-900):

```r
#' Copy year control icon to output directory
#'
#' Ensures the year control SVG icon is available in the output directory
#' for HTML maps to reference. Icon is stored in inst/icons/ and copied
#' to aq_maps/ when needed.
#'
#' @return Path to the copied icon file
#' @keywords internal
copy_year_control_icon <- function() {
  source_icon <- "inst/icons/year-control-icon.svg"
  output_dir <- "aq_maps"
  dest_icon <- file.path(output_dir, "year-control-icon.svg")

  # Ensure output directory exists
  if (!dir.exists(output_dir)) {
    dir.create(output_dir, recursive = TRUE)
  }

  # Copy icon if source exists
  if (file.exists(source_icon)) {
    file.copy(source_icon, dest_icon, overwrite = TRUE)
  } else {
    warning("Year control icon not found at: ", source_icon)
  }

  return(dest_icon)
}
```
