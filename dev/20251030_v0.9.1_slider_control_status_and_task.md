## Technical Facts

1. `HTMLWidgets.find()` requires CSS selector string (e.g., `"#htmlwidget-123"`)
2. Widget object is not the Leaflet map - must extract via `.getMap()`, `.map`, or `._map`
3. `hideGroup(map, "2022")` removes layers from map - they don't appear in `map.eachLayer()`
4. Calling `removeLayer()` during `eachLayer()` iteration causes layers to be lost
5. `htmlwidgets::onRender()` timing relative to `hideGroup()` is unclear
