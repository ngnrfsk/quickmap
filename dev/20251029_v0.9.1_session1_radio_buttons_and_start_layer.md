## Fix #2: Select Start Layer (Priority: HIGH)

### Issue
Maps currently show all years or first year on load. Should default to showing **latest (highest numbered) year** on initial load.

**User Requirement**: No new parameters - just change internal default behavior.

### Current Behavior
```r
# All years may be visible initially, or first year is shown
# Should default to showing LATEST year instead
```

### Proposed Solution
Change internal logic to show latest year by default using `hideGroup()`:

```r
# Inside create_pollution_map() after layers are added
# Determine which years are available
all_years <- sort(unique(c(dt_years, bl_years)))  # All years from data

if (length(all_years) > 0) {
  latest_year <- max(all_years)  # Highest numbered year

  # Hide all year layers except the latest
  for (yr in all_years) {
    if (yr != latest_year) {
      group_name <- paste0("Year ", yr)
      map <- hideGroup(map, group_name)
    }
  }
}

# Static layers (schools) are never hidden - always visible
```

### Key Points
- **No new parameters** - internal logic change only
- **No function signature changes** - backward compatible
- **No documentation changes needed** - just changes default behavior
- Latest = max(years) - highest numbered year
- Schools/static layers always visible
- Users can still switch years via radio buttons after load

### Implementation Steps
1. **Locate** layer addition loop in `create_pollution_map()` (~line 2315-2350)

3. **Calculate** latest_year = max(all_years)
4. **Loop** through all years, call `hideGroup()` for non-latest years
5. **Ensure** static layers (schools) are not affected by hideGroup()
6. **Test** with various year combinations
