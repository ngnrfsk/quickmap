### 🟠 MAJOR Issues

#### M1: Hardcoded Config Names in `load_spatial_data_sources()`

**Location:** `R/quickmap.R` lines 1808-1822 **Severity:** MAJOR - Limits extensibility

**Problem:** The function still has hardcoded logic for 3 specific config names:

``` r
if (config_name == "bl_nodes") {
  # Hardcoded
} else if (config_name == "dt_sites") {
  # Hardcoded
} else if (config_name == "schools") {
  # Hardcoded
} else {
  warning("Unknown config_name: ", config_name, ". Skipping.")  # 4th network triggers this!
}
```

**Why it works anyway:** The 4th network (`aurn`) is passed as an **sf object** (line 116 in test_4network_mock.R), so it hits the `if (inherits(data_src, "sf"))` branch (line 1804) and bypasses the hardcoded config_name checks.

**Why it's still broken:** - If user passes AURN as a **file path** instead of sf object, it will hit line 1821 and be skipped with warning - Config system is supposed to be data-driven, but data loading is still hardcoded - Violates Step 1's goal: "enables unlimited data sources"

**Correct Implementation:** The function should load YAML config first to determine data type/format, then load accordingly:

``` r
load_spatial_data_sources <- function(data_sources, data_configs, pollutant) {
  loaded_data <- list()

  for (i in seq_along(data_sources)) {
    data_src <- data_sources[[i]]
    config_name <- data_configs[i]

    # Handle sf objects directly
    if (inherits(data_src, "sf")) {
      loaded_data[[config_name]] <- data_src
      next
    }

    # Load config to determine how to load file
    config <- load_data_source_config(config_name)

    # Generic file loading based on config metadata
    if (config$static) {
      # Static layers: CSV with Easting/Northing
      result <- load_data_file(data_src, "csv", c("Easting", "Northing"))
      if (!is.null(result)) {
        loaded_data[[config_name]] <- result$data |> transform_to_wgs84()
      }
    } else {
      # Temporal layers: check monitoring_type or file extension
      if (!is.null(config$openair_import_function)) {
        # RData with OA format
        loaded_data[[config_name]] <- load_data_file(data_src, "rdata", pollutant = pollutant)$data
      } else {
        # CSV with year columns
        result <- load_data_file(data_src, "csv", c("Easting", "Northing"))
        if (!is.null(result)) {
          loaded_data[[config_name]] <- get_temporal_data(result$data) |> transform_to_wgs84()
        }
      }
    }
  }

  # Maintain backward compatibility
  list(
    dt = loaded_data[["dt_sites"]],
    sensor = loaded_data[["bl_nodes"]],
    school = loaded_data[["schools"]],
    dt_enabled = !is.null(loaded_data[["dt_sites"]]),
    sensor_enabled = !is.null(loaded_data[["bl_nodes"]]),
    school_enabled = !is.null(loaded_data[["schools"]]),
    all_data = loaded_data,
    configs = data_configs
  )
}
```

**Impact:** Limits 4th network to sf objects only, prevents true file-based extensibility.

#### M2: Missing Validation - `layer_config$static` Could Be NULL

**Location:** `R/quickmap.R` lines 1508, 1725, 1762 **Severity:** MAJOR - Incorrect branching

**Problem:** Code assumes `layer_config$static` exists and is boolean:

``` r
if (!layer_config$static) {  # Line 1508, 1725
  # temporal logic
} else {                     # Line 1761
  # static logic
}
```

**Edge Case:** If YAML config omits `static` field or YAML parser returns NULL, `!NULL` evaluates to `TRUE` in R, causing incorrect branching.

**Fix Option 1:** Add NULL check:

``` r
if (!isTRUE(layer_config$static)) {  # FALSE or NULL treated as temporal
  # temporal logic
} else {
  # static logic
}
```

**Fix Option 2:** Enhance validation in `load_data_source_config()` to fail if `static` is missing:

``` r
required_fields <- c("id", "icon_shape", "static")
```

(Already present at line 450, but should verify it actually fails for missing fields)

**Recommendation:** Use Fix Option 1 for robustness.
